### **[1. Customer Churn Prediction (Machine Leaning,Deep Leaning,tableau,keras)](https://github.com/Atharv-M-Patil/Customer-Churn-Predication)**

This project focuses on predicting customer churn for a bank using Machine Learning and Deep Learning techniques. Churn prediction helps banking sectors identify customers who are likely to leave their services and take proactive actions to retain them.

---

## 🚀 Project Overview

Customer churn is a critical business problem in the financial sector. The goal of this project is to:
✔ Analyze customer behavior  
✔ Train predictive models to detect churn  
✔ Evaluate model performance  
✔ Visualize insights using Tableau  

We used multiple ML & DL models and compared performance to select the best performer.  
Keras-based Neural Network provided improved predictive capability for complex patterns.
